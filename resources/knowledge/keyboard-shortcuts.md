# Keyboard Shortcuts

Shortcuts use `Cmd` on macOS and `Ctrl` on Windows/Linux.

## Global

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl+P` | Command Palette |
| `Cmd/Ctrl+,` | Settings |
| `Cmd/Ctrl+N` | New Project |
| `Cmd/Ctrl+O` | Open Folder |
| `Cmd/Ctrl+1–9,0` | Switch view (Planner, Editor, Designer, Orchestrator, Telemetry, Memory, Reviews, Diagnostics, Source Control, Reporter) |

## Editor & Navigation

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl+B` | Toggle sidebar |
| `Cmd/Ctrl+F` | Find in files |
| `Cmd/Ctrl+Shift+P` | Show all commands |

## Workflow & Views

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl+P` | Command Palette (also opens search) |

## Kanban

| Shortcut | Action |
|----------|--------|
| `N` | New story |
| `E` | Edit selected story |
| `Delete` | Archive selected story |
| `Left/Right` | Move story between lanes |

## Workflow Canvas

| Shortcut | Action |
|----------|--------|
| `Space` | Pan canvas |
| `Scroll` | Zoom |
| `Delete` | Delete selected node |
| `Cmd/Ctrl+Z` | Undo |
| `Cmd/Ctrl+Shift+Z` | Redo |
