# Keyboard Shortcuts

## Global

| Shortcut | Action |
|----------|--------|
| `Cmd+P` | Command Palette |
| `Cmd+Shift+P` | Show all commands |
| `Cmd+Shift+W` | Toggle Workflow Builder |
| `Cmd+Shift+K` | Toggle Kanban Board |
| `Cmd+Shift+T` | Toggle Terminal |
| `Cmd+Shift+M` | Toggle CapEx Dashboard |
| `Cmd+Shift+S` | Toggle Settings |

## Editor

| Shortcut | Action |
|----------|--------|
| `Cmd+B` | Toggle sidebar |
| `Cmd+J` | Toggle terminal panel |
| `Ctrl+Shift+`` | New terminal |
| `Cmd+Shift+F` | Search across files |
| `Cmd+G` | Go to line |

## Chat

| Shortcut | Action |
|----------|--------|
| `Enter` | Send message |
| `Shift+Enter` | New line |
| `Cmd+L` | Clear chat |
| `Cmd+Shift+L` | New chat session |

## Kanban

| Shortcut | Action |
|----------|--------|
| `N` | New story |
| `E` | Edit selected story |
| `Delete` | Archive selected story |
| `Left/Right` | Move story between lanes |

## Workflow Canvas

| Shortcut | Action |
|----------|--------|
| `Space` | Pan canvas |
| `Scroll` | Zoom |
| `Delete` | Delete selected node |
| `Cmd+Z` | Undo |
| `Cmd+Shift+Z` | Redo |
