Welcome, Operator. This tutorial will walk you through the standard **Industrial Pipeline** for developing a feature in COPERNICUS.

## STEP 1: SCAFFOLDING THE INTENT
Every feature begins with a **Strategic Intent**.
1. Open the **Studio [F2]** storyboard.
2. In the **Strategic Chat**, type:
   `/plan implement a new theme-aware status indicator in the top header`
3. Watch as the **Architect** persona generates a new Story file in `docs/stories/`.

## STEP 2: THE KANBAN ACTIVATION
A story is "cold" until it is activated on the Kanban board.
1. Flip the Strategic Chat panel (click the **[⌘]** icon) to reveal the **Kanban Board**.
2. Drag the new Story from the **Backlog** column to **Ready for Implementation**.
3. Notice the **System Pulse** in the Status Bar turns to a solid amber glow.

## STEP 3: DELEGATION & IMPLEMENTATION
You are the Conductor; let the agents be the instruments.
1. In the Strategic Chat, delegate the implementation:
   `/delegate agent=senior_dev task="Implement the status indicator in App.tsx using the new theme variables"`
2. Use the **Blueprint [F1]** view to monitor the **State Ledger** as the agent modifies the codebase.

## STEP 4: INDUSTRIAL VERIFICATION
We do not ship without proof.
1. Use the **Engine Room [F3]** storyboard.
2. Click **make test** on the **Command Deck**.
3. Run the security audit: `/audit`
4. Run the performance check: `/pi_check`

## STEP 5: DEPLOYMENT IGNITION
Once all verification checks are green, push to the Core.
1. Return to the **Engine Room [F3]**.
2. Click **make deploy** on the Command Deck.
3. Observe the deployment telemetry stream in the terminal.

**OPERATION COMPLETE.** You have successfully navigated the COPERNICUS pipeline.
