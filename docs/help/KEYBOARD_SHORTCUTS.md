# COPERNICUS IDE — Keyboard Shortcuts

| Shortcut (macOS) | Shortcut (Win/Linux) | Action | Context |
|---|---|---|---|
| **Global** ||||
| `Cmd+P` | `Ctrl+P` | Open command palette | Global |
| `Cmd+K` | `Ctrl+K` | Toggle spotlight search | Global |
| `F1` | `F1` | Blueprint view (Kanban + CapEx) | Global |
| `F2` | `F2` | Studio view (Editor + Chat) | Global |
| `F3` | `F3` | Engine Room (Terminal + Telemetry) | Global |
| `F4` | `F4` | CapEx dashboard | Global |
| `F5` | `F5` | Workflow canvas | Global |
| **Editor** ||||
| `Ctrl+S` | `Ctrl+S` | Save current file | Editor |
| `F12` | `F12` | Go to definition | Editor |
| `Shift+F12` | `Shift+F12` | Find all references | Editor |
| `Cmd+Shift+A` | `Ctrl+Shift+A` | Ghost Mode — accept suggestion | Editor |
| `Cmd+Shift+R` | `Ctrl+Shift+R` | Ghost Mode — reject suggestion | Editor |
| `Shift+Alt+F` | `Shift+Alt+F` | Format document | Editor |
| `Cmd+/` | `Ctrl+/` | Toggle line comment | Editor |
| `Cmd+Z` | `Ctrl+Z` | Undo | Editor |
| `Cmd+Shift+Z` | `Ctrl+Y` | Redo | Editor |
| **Chat Panel** ||||
| `Enter` | `Enter` | Send message | Chat |
| `Shift+Enter` | `Shift+Enter` | Insert new line (no send) | Chat |
| `Cmd+Shift+C` | `Ctrl+Shift+C` | Attach file context | Chat |
| `Cmd+M` | `Ctrl+M` | Open model picker | Chat |
| **Workflow Canvas** ||||
| `N` | `N` | Add new node (when canvas focused) | Workflow |
| `Del` / `Backspace` | `Del` / `Backspace` | Delete selected node or edge | Workflow |
| `R` | `R` | Run workflow from selected node | Workflow |
| `Esc` | `Esc` | Deselect / cancel drag | Workflow |
| `Cmd+Z` | `Ctrl+Z` | Rewind to previous snapshot | Workflow |
| **Kanban** ||||
| `N` | `N` | New story (when board focused) | Kanban |
| `/` | `/` | Open filter bar | Kanban |
| `Esc` | `Esc` | Clear filter / close modal | Kanban |

> **Note:** Shortcuts marked with a canvas context (`Workflow`, `Kanban`) require that the respective panel has keyboard focus. Click the panel first if shortcuts aren't responding.
