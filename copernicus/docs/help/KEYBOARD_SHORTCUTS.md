# Keyboard Shortcuts

This document outlines the keyboard shortcuts available in Copernicus.

## Global

| Shortcut (macOS)       | Shortcut (Win/Linux)   | Action                               | Context |
| :--------------------- | :--------------------- | :----------------------------------- | :------ |
| `Cmd+P`                | `Ctrl+P`               | Open Command Palette                 | Global  |
| `Cmd+S`                | `Ctrl+S`               | Save current file/workflow           | Global  |
| `F1`                   | `F1`                   | Switch to Editor View                | Global  |
| `F2`                   | `F2`                   | Switch to Chat Panel                 | Global  |
| `F3`                   | `F3`                   | Switch to Workflow Canvas            | Global  |
| `F4`                   | `F4`                   | Switch to Kanban Board               | Global  |
| `F5`                   | `F5`                   | Switch to Debug Panel                | Global  |
| `Cmd+Shift+A`          | `Ctrl+Shift+A`         | Accept Ghost Mode suggestion         | Global  |
| `Cmd+Shift+R`          | `Ctrl+Shift+R`         | Reject Ghost Mode suggestion         | Global  |

## Editor

| Shortcut (macOS)       | Shortcut (Win/Linux)   | Action                               | Context |
| :--------------------- | :--------------------- | :----------------------------------- | :------ |
| `F12`                  | `F12`                  | Go to Definition                     | Editor  |
| `Shift+Alt+F`          | `Shift+Alt+F`          | Format Document                      | Editor  |

## Chat Panel

| Shortcut (macOS)       | Shortcut (Win/Linux)   | Action                               | Context |
| :--------------------- | :--------------------- | :----------------------------------- | :------ |
| `Enter`                | `Enter`                | Send message                         | Chat    |
| `Shift+Enter`          | `Shift+Enter`          | New line                             | Chat    |

## Workflow Canvas

| Shortcut (macOS)       | Shortcut (Win/Linux)   | Action                               | Context         |
| :--------------------- | :--------------------- | :----------------------------------- | :-------------- |
| `A`                    | `A`                    | Add new node                         | Workflow Canvas |
| `R`                    | `R`                    | Run selected node                    | Workflow Canvas |
| `Delete` / `Backspace` | `Delete` / `Backspace` | Delete selected node                 | Workflow Canvas |
