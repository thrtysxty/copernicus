COPERNICUS has an integrated terminal at the bottom of the IDE.

**Opening the terminal:**
- Click the terminal icon in the bottom bar, or press Ctrl+` (backtick)
- The terminal opens in the current project directory

**Terminal tabs:**
- Click **+** in the terminal header to open a new tab
- Click a tab to switch between sessions
- Click **✕** on a tab to close it (requires at least one other tab to be open)

**Running commands:**
- The terminal is a full shell session (bash/zsh depending on your system)
- Type commands normally — output appears in the terminal window
- Use the terminal to run build commands, tests, git operations, etc.

**Agent terminals:**
- When the workflow builder runs an agent with shell access, it opens a dedicated terminal tab marked with a busy indicator (spinning icon)
- Agent terminal output streams in real time
- Click the **■ Stop** button on an agent tab to terminate it

**Spotlight / expand:**
- Click the Maximize icon in the terminal header to spotlight the terminal (hides other panels)
- Click it again to return to normal layout

**Troubleshooting:**
- If the terminal is blank and not accepting input, try clicking inside the terminal area to focus it
- If a tab is stuck on "busy", click the Stop button or close and reopen the tab
