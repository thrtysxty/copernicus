COPERNICUS is an AI-native IDE for agent-driven software development. It combines a Kanban project board, a workflow builder, an integrated terminal, a Monaco code editor, and a chat panel — all wired to cloud and local AI models.

**Activity Bar** (left strip of icons) — the main navigation:
- Kanban icon → opens the story/project board
- Chat icon → opens the AI chat panel
- Files icon → opens the file tree and editor
- Workflow icon → opens the workflow builder
- Telemetry icon → opens the Command Center (LSP status, model info)
- Settings icon (gear) → opens the Settings panel

**First launch checklist:**
1. Add at least one provider API key in Settings → Auth
2. Set your default chat model in Settings → Models
3. Connect a Git repository via Settings → Git or the Source Control view
4. Open the Kanban board and create your first story

The status bar at the bottom shows: active model, LSP status, token count, and session cost.
